# Better Anvils v1.0.0 RC1 — Minecraft Fabric 26.2

This is the first **release candidate**, published as a GitHub **prerelease** rather than a fully qualified stable release. The jar is produced from the release commit only after the repository's build, automated GameTests, client GameTests, headless server startup, and optional-GUI-free client startup checks all pass.

## Features

- Default **50% XP discount** on valid anvil operations, rounded up to at least one level.
- Anvil maximum of **100 levels after discount** (inclusive), configurable up to 500.
- Native in-game settings with **Mod Menu + Cloth Config** (optional client-side dependencies): Minecraft → Mods → Better Anvils → Configure → Save.
- Automatic JSON persistence at `config/better-anvils.json`.
- Configurable prior-work XP tax treatment; vanilla enchantments, item components, repair results, and anvil wear are preserved.
- Server-authoritative costs in multiplayer, synchronized to matching modded clients.
- Costing respects enchantments defined by external datapacks such as HigherEnchants; no datapack or enchantment definitions are bundled.

## Requirements

- **Minecraft Java Edition 26.2**
- **Fabric Loader 0.19.3+**, **Fabric API 0.161.0+26.2**
- Java 25 runtime.
- Install Better Anvils and Fabric API on both the server and the client for multiplayer.
- Optional for in-game configuration: Mod Menu 20.0.3 and Cloth Config 26.2.155 on the client.

## Installation

1. Download **`better-anvils-1.0.0.jar`** below (not a `-sources.jar`).
2. Place the jar in the Minecraft Fabric instance `mods` directory, with the required Fabric API.
3. For multiplayer, install the same Better Anvils jar on the dedicated server and each connecting client.
4. Launch the game. Use **Mods → Better Anvils → Configure** with the optional UI mods; click Save to update the file automatically in singleplayer. Dedicated-server administrators edit `config/better-anvils.json` on the stopped server and restart.

## Verified versus not yet qualified

**Automated checks:** build, unit tests, server GameTests, client configuration GameTests, server startup, and client startup without optional GUI dependencies are required to pass for publication. Previous HigherEnchants 1.4 testing confirmed registry-defined Sharpness VIII and compatibility behavior, with added edge-case tests on the release candidate.

**Still requires manual qualification:** real two-client dedicated multiplayer behavior with unlike configurations, complete Mod Menu navigation and restart UX, and the full range of HigherEnchants equipment combinations and other anvil mod conflicts. These are known **unverified scenarios**, not claims of compatibility testing success.

This is intended for testing before declaring a stable release. Report problems at the repository's Issues tab, including the Minecraft and Fabric versions and the relevant `latest.log`.
